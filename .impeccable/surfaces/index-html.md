## Direction contract

THESIS: This is a moto elétrica's instrument cluster repurposed to read content, not speed — it refuses the generic "card feed" every research/curation tool ships, because the product's own subject (moto elétrica) IS the instrument language, and a dashboard's job — surface three equal-weight readings at a glance, mark state at a glance, stay legible one-handed — is exactly this task's job.

OWN-WORLD: Near-black instrument body (#0b0d0c ground), one warm amber/copper signal accent (regen-brake indicator color, not the cliché neon cyan) for the single most important state per item, plus a cool teal used only for the "pronto" state light — restrained palette, two functional colors max, never decorative. Body/labels in system-ui sans (workhorse, gets out of the way). Every numeral (view counts, duration, dates, item count) set in a monospaced face (tabular figures — a real gauge doesn't jiggle digits) picked at build time by measuring against the system stack. Thin 1px instrument-panel rules only where a gauge boundary exists, never as decoration; no glow/bloom blur — precision over mood.

STORY: Opens on today's rodada as a bank of instrument tiles, one per collected video, each showing three equal "gauges" — tema/gancho/formato readout, vídeo-fonte (plataforma + link, thumbnail-style swatch), roteiro readiness — plus a state light (pronto/pulado/falhou). User scans the panel top-to-bottom on the phone right after the push notification, taps a tile to expand the full roteiro inline. A search/filter strip (platform, date range, keyword) sits as a secondary control row, styled like a dash's trip-computer sub-panel, for the "buscar coisa antiga" habit already confirmed.

FIRST VIEWPORT (mobile, 390w): fixed top instrument strip — "banco-motos" wordmark left, rodada count + date right, thin amber underline. Below it, the trip-computer search/filter row (collapsed to an icon-button by default, expands on tap — doesn't compete with the tiles for space). Then the tile bank starts immediately: first tile fully visible, its three gauges laid out as a horizontal triad (equal width), state light top-right corner of the tile.

FORM: assigned direction (candidate 4 of the grounded list, seed key 0cd9939d), chosen over challengers "teletexto de emissora" (declined — donated: disciplined color-per-state-role) and "fila cracktro" (declined — donated: shared clock driving state-light pulse rhythm); competitive alternate "feed vertical TikTok" set aside per user choice.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
